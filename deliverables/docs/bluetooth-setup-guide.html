Bluetooth Setup Guide 1 / 3
What You Need
Confirm you have the following before the event starts.
Polar Optical Sensor
Polar Verity Sense or Polar OH1 arm-band. Fully charged before use.
Laptop or Desktop PC
Windows or macOS with Bluetooth — built-in or via USB dongle.
Google Chrome or Microsoft Edge
Web Bluetooth only works in these two browsers. Not Safari, not Firefox.
Bluetooth Enabled
Switch Bluetooth on in your system settings before opening the dashboard.
iOS / iPhone
Web Bluetooth is not available on iPhone or iPad. The dashboard must run on a laptop or an Android device in Chrome. iPhones can still be used as the remote control — see the remote control section of this guide.
Prepare & Wear the Sensor
The sensor must sit against the skin to read heart rate accurately.
01
Charge the sensor before the event
Attach the Polar sensor to its USB magnetic charger. A full charge takes 60–90 minutes and will last all day. The LED pulses red while charging and turns solid green when complete.
02
Fit the band on the participant's upper arm
Slide the sensor pod into the arm-band strap. Position it on the upper arm, 2–3 cm above the elbow, with the optical lens facing inward against the skin. The band should be snug — not uncomfortable — with no room to slide a finger underneath.
03
Power on the sensor
Press and hold the single button for 2 seconds until the LED flashes green. The sensor begins advertising via Bluetooth automatically. If the LED does not light, the battery is flat — charge before continuing.
Between participants
The sensor does not need to be powered off between participants. Remove the band, pass it to the next person and the sensor will re-pair automatically when the next session starts.

Bluetooth Setup Guide 2 / 3
Connect the Sensor to the Dashboard
This is done once at the start of the event — not before every participant.
01
Open the dashboard in Chrome or Edge
Navigate to quadient-stress-dashboard.vercel.app. You should see the "Next Challenger" idle screen below.
The dashboard idle screen — ready and waiting.
02
Open Operator Controls
Press Enter on your keyboard, or click the Quadient logo in the top-left corner. A panel will slide in from the right.
Operator Controls panel — Demo Mode is selected by default.
03
Select Polar Sensor as the data source
Under Data Source, click Polar Sensor. It will highlight in blue and the Connect Sensor button will become active.
Polar Sensor selected — Connect Sensor is now active.

Bluetooth Setup Guide 3 / 3
Pair and Start
Final steps to go live.
04
Click Connect Sensor
Chrome will display a Bluetooth device picker. Ensure the Polar sensor is powered on and being worn — it must be advertising before it appears in the list. Select the device named Polar Sense… or Polar OH1… and click Pair.
Device not appearing?
Confirm the sensor is powered on and within 5 metres. Close the picker and click Connect Sensor again to re-scan. It can take 5–10 seconds to appear.
05
Confirm the connection
The panel will show Connected along with the sensor's battery percentage. The header bar at the top of the dashboard will also update.
06
Start a session
Click Start New Session in Operator Controls, or use the mobile remote control — open the dashboard URL on any phone, add ?remote to the address, and enter PIN 5014. The waveform and BPM display will activate immediately.
Between participants
The sensor stays connected for the full event. For each new participant, click End Session then Next Participant — no need to reconnect Bluetooth each time.
Troubleshooting
Common issues on the day.
Problem Fix
Device not showing in Bluetooth picker Ensure the sensor is powered on. Move it closer. Close the picker and click Connect Sensor again.
Connection drops mid-session The dashboard auto-reconnects. If it fails, open Operator Controls and click Connect Sensor again — the session will resume.
"Web Bluetooth not supported" error Switch to Google Chrome or Microsoft Edge. Bluetooth does not work in Safari or Firefox.
BPM reading stuck or not moving Ensure the sensor is snug against the skin. Use the + / − HR Override buttons on the mobile remote control to manually adjust the displayed value.
Sensor LED not lighting on power-on Battery is flat. Connect to the USB charger for at least 30 minutes before the next use.
Remote control shows invalid access code Enter PIN 5014. Ensure the URL has ?remote appended and you are on the correct dashboard address.
