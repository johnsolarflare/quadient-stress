Sensor Setup
1 / 3
What You Need
Confirm you have the following before the event starts.
Polar Optical Sensor
Polar Verity Sense or Polar OH1 arm-band. Fully charged before use.
Laptop or Desktop PC
Windows or macOS with Bluetooth — built-in or via USB dongle.
Google Chrome
The dashboard requires Chrome. Bluetooth does not work in Safari or Firefox.
Bluetooth Enabled
Switch Bluetooth on in your system settings before opening the dashboard.
iPhone & iPad
The dashboard must run on a laptop or Android device in Chrome. iPhones can still be used as the mobile remote control — see page 3.
Prepare & Wear the Sensor
The sensor must sit against the skin to read heart rate accurately.
01
Charge the sensor before the event
Attach the Polar sensor to its USB magnetic charger. A full charge takes 60–90 minutes and will last all day. The LED pulses red while charging and turns solid green when complete.
02
Fit the band on the wrist or upper arm
The sensor works on the wrist (like a watch) or the upper arm — wrist is usually easiest at an event. Place the optical lens flat against the skin and tighten the band so it's snug with no room to slide. A loose sensor will give unreliable readings.
03
Power on the sensor
Press and hold the single button for 2 seconds until the LED flashes green. The sensor begins advertising via Bluetooth automatically.
Between participants
The sensor does not need to be powered off. Remove the band and pass it to the next person — the sensor will re-pair automatically when the next session starts.

Connect & Start
2 / 3
Connect the Sensor to the Dashboard
Done once at the start of the event — not before every participant.
01
Open the dashboard in Google Chrome
Navigate to quadient-stress-dashboard.vercel.app. You should see the idle screen below.
The dashboard idle screen — ready and waiting.
02
Open Operator Controls & select Polar Sensor
Press Enter on the keyboard (or click the Quadient logo, top-left). In the panel that opens, click Polar Sensor — it will highlight in blue and the Connect Sensor button will become active.
Polar Sensor selected — Connect Sensor is now active.
03
Click Connect Sensor
Chrome will show a Bluetooth device picker. Ensure the sensor is powered on and being worn. Select the device named Polar Sense… or Polar OH1… and click Pair.
Device not appearing?
Confirm the sensor is powered on and within 5 metres. Close the picker, click Connect Sensor again and wait 5–10 seconds.
04
Confirm the connection
The panel will show Connected along with the sensor's battery percentage. The header bar at the top of the dashboard will also update.
05
Start a session
Click Start New Session in Operator Controls — or use the mobile remote (see page 3). The waveform and BPM display will activate immediately.

For each new participant: click End Session then Start New Session. No need to reconnect Bluetooth each time.
Bluetooth Range — Important
The participant must stay within approximately 10 metres of the laptop running the dashboard for a reliable connection. In a busy event space with crowds and obstacles, treat 5–8 metres as the safe working range. If the participant roams further, the connection may drop — the dashboard will auto-reconnect, but readings will pause until they return to range. Position the laptop as close to the experience zone as possible.

Override & Sensitivity

Keeping the Experience Engaging
Stress responses are personal — these tools let you tune the experience in real time.
Some participants will barely change heart rate; others spike quickly. Neither is wrong. The two controls below let you make real-time adjustments so the display always looks dynamic and engaging.
Mobile Remote — Live BPM Nudge
Use any phone in Chrome to start sessions and push the heart rate display up or down.
01
Open the remote & unlock
Open Google Chrome on any phone and go to quadient-stress-dashboard.vercel.app/?remote. Enter PIN 5014 and tap Unlock.
Enter PIN 5014
Session live — tap + or −
02
Start, stop, and nudge BPM
Tap Start Session to begin. Once live, the + and − buttons appear — each tap adjusts the displayed BPM by ±2, instantly reflected on the main screen. Use these whenever the experience feels flat to push the display into a higher zone.
Zone Sensitivity — Dashboard Setting
Controls how easily the display moves between colour zones. Adjust in Operator Controls at any time.
01
Open Operator Controls — find the slider
Press Enter (or click the Quadient logo). The Zone Sensitivity slider is in the middle of the panel.
Default is 1.0× (Normal). Changes take effect immediately.
02
Choose the right setting
SettingHow it behavesBest for
High (2×–3×) Small HR rise triggers a zone change — reacts quickly Calm participants whose BPM barely moves
Normal (1×) Zones change at natural thresholds Default — start here for everyone
Low (0.5×) Larger HR rise needed to change zone Participants already at a high resting rate
Tip: Start at 1×. If nothing is moving after 30 seconds, slide up to 2× or 3×.
Troubleshooting
ProblemFix
Device not showing in Bluetooth picker Ensure sensor is powered on and within 5 metres. Close and reopen the picker.
Connection drops mid-session Check the participant is within 5–8 metres of the laptop. The dashboard will auto-reconnect once back in range. If it doesn't, open Operator Controls and click Connect Sensor again.
BPM reading not moving Check the sensor is snug against the skin. Use the + / − buttons on the mobile remote to manually adjust.
"Web Bluetooth not supported" error Switch to Google Chrome. Bluetooth does not work in Safari or Firefox.
Remote shows invalid access code Enter PIN 5014. Ensure the URL includes ?remote at the end.
