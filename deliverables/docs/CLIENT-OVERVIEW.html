Quadient Stress Dashboard

Client Overview  ·  Live demo: quadient-stress-dashboard.vercel.app

Overview

A real-time biometric activation built for live environments

The Quadient Stress Dashboard is an interactive experience designed for events, exhibitions, and workplace activations. Participants wear a Polar heart rate sensor while their physiological response is visualised instantly on a shared screen — translating biometric data into a clear, engaging narrative of "stress" using colour, motion, and light-touch office humour.

The system is built for efficient throughput, allowing a single operator to manage multiple participants consecutively with minimal intervention.

What the Experience Measures

Heart rate mapped to five cognitive stress zones

Each session begins with a short baseline calibration (~10 seconds), adapting dynamically to the individual's resting level so results are relative and comparable across participants.

Experience Flow

Three states — Idle, Active, Complete

Idle "Next Challenger" holding state with rotating workplace prompts. The event leaderboard builds in the background throughout the day.
Active Session — Composed (Z1) Live ECG waveform, BPM ring, zone gauge, session timer, and Min/Avg/Max stats. Blue — participant is calm.
Active Session — Overloaded (Z5) All visuals shift to deep red. The waveform intensifies, gauge fills, and the ambient background glow matches the zone.
Session Complete Peak BPM as the headline result, with Avg, Min, and Duration below. The event leaderboard updates at the bottom.
Operator Control

Full control without disrupting the main display

Operator Panel Slides in from the right edge. Switch data source, manage the Polar sensor, start/end/reset sessions, export a CSV, and clear data between activations.
Remote Control — Operator's Phone A secure PIN link opens a mobile control view. Start, end, and reset sessions from anywhere in the room, synced live to the main display via Firebase.
Technical Notes

A few things worth knowing

  • No sensor required to demo — a built-in simulation mode runs the full experience without any hardware
  • All data stays local — nothing is stored externally; session stats persist in the browser for the duration of the event
  • Brand-ready — colours, typography, and UI reflect Quadient's visual identity throughout
Copy & Messaging

All on-screen copy is customisable — or can be removed entirely

The dashboard includes a library of contextual puns written for an office environment, zone-aware and rotating throughout each session. All copy can be swapped for brand-specific messaging, neutralised, or switched off.
